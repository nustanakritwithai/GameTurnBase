## 195. A shipped migration told the operator a zero meant safe, and the zero was a moving window

**Operator:** HetCreep · **Agent:** Claude Code (task #92) · **2026-08-11**

## 200. The anchor tolerance nobody publishes, recovered by measuring the people who never wrote it down

The sweep in item 199 proved that no tool publishes a cross-frame anchor tolerance, and gave the
structural reason: no tool stores a per-frame anchor it could validate. HetCreep did not accept that as
the end of it — "ไม่ต้องพึ่งงานเราอย่างเดียว" — and the objection was right. A number nobody writes down can

**Method, stated so it can be re-run rather than trusted.** Alpha threshold 8; foot band = the bottom
3.75% of character height; foot centre taken inside that band rather than across the whole silhouette,
because a staff or a tail moves the bounding box without moving the feet. Two axes kept strictly apart:
`inDir` (drift within one direction's own cycle) and `xDir` (drift between each direction's mean foot
line). The first may legitimately be large — a stride lifts a foot. The second has no excuse.

**Corpora.** Two, both openly licensed, both measured rather than cited: a community spritesheet
standard with a fixed 64 px cell and hundreds of contributors, and a two-decade open strategy game
shipping one file per frame. 314 external animation sets after kind classification.

**HetCreep's second objection found the real variable.** They suspected drift scaled with character
size. Tested directly: correlation between character height and drift, across all six kind × axis cells,
came back **-0.594, 0.131, 0.293, 0.214, -0.107, 0.268** — not one strong positive, and the strongest is
*negative*. Drift does not scale with size. What the data showed instead was that **animation kind is the
variable**: in one corpus, static sets hold a median of 0 px with 82% at exactly zero, while action sets
run a median of 3 and a maximum of 37. A body that is planted holds its feet; a body that lunges does
not, and should not.

**The base.** Ceilings built from external corpora only (n=314, heights 24-82 px), then this project's
own sets scored against them afterwards — building the ceiling from a pool containing the sets under
judgement would have been circular, and would have let the defective sets widen the very band meant to
catch them.

    alignment error     base = 1 px, ABSOLUTE, does not scale with character height
                        pose-hold x1  ·  locomotion x2  ·  action x3   (xDir)
    depicted movement   NOT absolute — a bigger character's stride really does cross more pixels
                        locomotion <= 27% of character height  ·  action <= 23%   (inDir)

The absolute half is decided by evidence, not preference: well-made pose-hold sets land on 0-1 px at
character heights from 24 px to 370 px, a 15x span. The reason is physical — this drift is an authoring
alignment error, bounded by the precision of the hand and the tool, not by the size of the subject.
Forcing one formula across both halves would have been wrong in a visible way: one action set measures
22.79% of character height, comfortably inside the proportional band, while reading as a 14x failure in
absolute pixels.

**Scored, this repository fails hardest exactly where the band is tightest.** The three turn sets are
xDir pose-hold cases — eight single-frame directions, body planted, only the facing changing — and they
come in at 12x, 31x and 51x over. `spear-warrior-stop-turn` holds 0 px on both axes and proves the band
is reachable here with this project's own tools.

**Honest limits, written into the document rather than around it.** Two corpora is evidence, not
consensus; a third could move the base by a pixel. The kind labels are unambiguous in one corpus and
inferred from filenames in the other, so the action band is if anything slightly wider than the truth.
No web-platform, commercial, or 3D-rendered-to-sprite corpus was measured. And the corpora measured
cannot resolve drift finer than one pixel, so these are ceilings evidenced from outside — never targets.
Targets come from a project's own best work, which at several hundred pixels of character height
measures zero.
